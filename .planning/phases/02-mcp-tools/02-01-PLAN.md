class PlaudClient:
    """Async context manager. Use as: async with PlaudClient() as client: ..."""

    async def get(self, path: str, **kwargs) -> dict:

        kwargs forwarded to httpx (e.g., params={"skip": 0, "limit": 100}).
        """

    async def __aenter__(self) -> "PlaudClient": ...
    async def __aexit__(self, exc_type, exc_val, exc_tb) -> None: ...
    async def aclose(self) -> None: ...

FastMCP usage pattern (fastmcp>=3.1.1):
```python
from fastmcp import FastMCP

mcp = FastMCP("plaud")

@mcp.tool()
async def my_tool(param: str) -> dict:
    async with PlaudClient() as client:
        response = await client.get("/some/path", params={"x": param})
        return response.get("data", {})

if __name__ == "__main__":
    mcp.run(transport="stdio")
```

**Mocking strategy:** Use `unittest.mock.AsyncMock` for `PlaudClient.get` (it's async). Patch as `"plaud_mcp.server.PlaudClient"` — replace the class so that `async with PlaudClient() as client` yields a mock whose `.get` is an `AsyncMock`.

Pattern for patching:
```python
from unittest.mock import AsyncMock, MagicMock, patch
import pytest

# Helper to build a mock PlaudClient context manager
def make_mock_client(*side_effects):
    mock_client = MagicMock()
    mock_client.__aenter__ = AsyncMock(return_value=mock_client)
    mock_client.__aexit__ = AsyncMock(return_value=None)
    if len(side_effects) == 1:
        mock_client.get = AsyncMock(return_value=side_effects[0])
    else:
        mock_client.get = AsyncMock(side_effect=list(side_effects))
    return mock_client
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client -> tool parameters | Tool caller (Claude or other MCP client) supplies file_id, query, days, dates — these cross into server-side logic |
| server.py -> PlaudClient | Tool code invokes authenticated HTTP client with constructed paths |
| PlaudClient -> Plaud API | Authenticated requests to api.plaud.ai |
| server.py -> S3 (via _fetch_s3_content) | Unauthenticated fetch of signed S3 URLs from content_list |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `get_file`, `get_transcript`, `get_summary` — `file_id` parameter | mitigate | Validate `file_id` is non-empty and stripped of whitespace before constructing URL path (`f"/file/detail/{file_id.strip()}"`) — raises `ValueError` on empty/whitespace input. file_id is user-supplied and used directly in URL construction; empty string would produce a malformed path. |
| T-02-02 | Information Disclosure / Tampering | `_fetch_s3_content` — S3 URL fetch | mitigate | Only fetch URLs sourced from `content_list[].data_link` returned by the authenticated Plaud API (server-provided). Never accept a `data_link` URL as a tool parameter from the MCP caller. This prevents an open-redirect / SSRF scenario where a caller could supply an arbitrary URL to the unauthenticated `httpx.get()` path. |
| T-02-03 | Information Disclosure | All transcript/summary tools — raw content returned to MCP client | accept | This is a single-user, self-hosted tool. The token owner is the sole user; no multi-tenant access control is needed. Full transcript/summary content is intentionally returned. Rationale: the threat is equivalent to the user reading their own data. |
| T-02-04 | Denial of Service | `search_transcripts` — unbounded API calls | mitigate | Limit file fetch to 50 (enforced in params: `"limit": 50`). Per-file transcript fetch errors are caught and skipped. Days parameter is user-controlled but does not affect API call count (client-side filter only). |
| T-02-05 | Spoofing | `check_connection` — token validity check | accept | `PlaudAuthError` raised on -10000 propagates to FastMCP as a tool error, which surfaces to the MCP client as an error response. No additional spoofing surface; the tool does not cache or store auth state. |
</threat_model>
