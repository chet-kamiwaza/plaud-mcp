## Trust Boundaries

- Host shell -> runtime helper script
- Runtime helper script -> Docker or Podman CLI
- Host env/.env -> container runtime
- Local host network -> HTTP MCP service on port 8080

## STRIDE Register

| threat_id | category | component | disposition | mitigation_plan |
|-----------|----------|-----------|-------------|-----------------|
| P5-01-T1 | Spoofing | runtime helper runtime selection | mitigate | Accept only explicit `docker` and `podman` runtime values; reject all other inputs with a usage error instead of shelling arbitrary commands. |
| P5-01-T2 | Information Disclosure | local HTTP port exposure | mitigate | Bind the local compose port to `127.0.0.1:8080:8080` so the development service is not exposed on all interfaces by default. |

</threat_model>
